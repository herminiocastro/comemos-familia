# Comemos — planificador familiar de comidas

PWA gratuita para decidir qué cocinar según tiempo disponible, objetivo nutricional, ingredientes y gustos de cada persona.

## Funciones incluidas
- Hasta 4 perfiles familiares configurables.
- Gustos y alimentos/platos que cada persona quiere evitar.
- Filtros por comida/cena, tiempo, objetivo nutricional, método de cocinado e ingredientes disponibles.
- Ocultación de platos incompatibles.
- Sugerencia de un segundo plato cuando una persona no quiera el plato principal.
- Recetas paso a paso y nutrición aproximada.
- Favoritos e historial.
- Menú semanal automático.
- Recetas propias de la familia.
- Copia de seguridad e importación en JSON.
- PWA instalable y funcionamiento offline.
- Los datos personales se guardan solo en el navegador mediante localStorage.

## Privacidad
El repositorio no contiene nombres ni preferencias personales de ninguna familia. Cada dispositivo configura sus propios perfiles localmente.

## Coste
La versión actual no usa API, backend ni servicios de pago: coste operativo 0 €.
